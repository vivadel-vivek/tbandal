# How-to guides

Per-role handbooks for Two Buds and a Leaf. Each one stands alone —
read just the one that matches your role on the site.

| Role | Guide | What you can do |
|---|---|---|
| Reader | [readers.md](readers.md) | Browse the catalog, read journal posts, use guided brewing — no account needed. |
| Member | [members.md](members.md) | Everything a reader can, plus library, sessions, recommendations, sharing. |
| Vendor | [vendors.md](vendors.md) | Self-edit your storefront page, see your clickout analytics, manage your teaware listings. |
| Contributor | [contributors.md](contributors.md) | Write reviews, publish posts, manage the catalog, respond to vendor edits. |
| Admin | [admins.md](admins.md) | Everything a contributor can, plus user role management, vendor URL changes, infrastructure. |

For the canonical feature inventory see [`../SPEC.md`](../SPEC.md). For
the route-by-route map with access tiers see
[`../SITEMAP.md`](../SITEMAP.md).

This snapshot is **frozen as of 2026-05-08** and will hold for one
month while we focus on writing reviews instead of building features.
